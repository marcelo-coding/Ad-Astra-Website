Tools

Software we built to run accounts as code

We automated each tool only after a manual task kept repeating.

MCP Servers

The servers that let AI agents run our stack

We wrote Model Context Protocol servers so AI agents can operate our stack directly, because an agent that can read reports and file changes beats ten dashboards.

Amazon Ads API

Amazon Ads MCP

This multi-seat MCP server runs over the Amazon Ads API and covers profiles, reporting, campaign and bulk operations, and AMC queries. It is the backbone that lets our bid engines and AI workflows touch every account we manage from one interface.

Google Workspace

Google Service Account MCP

This slim MCP server reads and writes Sheets, Docs, and Drive through a service account, because every forecast, tracker, and client report we run lands in a spreadsheet and the automation needs the same access We have.

Microsoft Graph

OneNote MCP

An MCP server for OneNote runs over the Microsoft Graph API with device code auth, paired with an extract and ingest pipeline that mirrors 667 notebook pages into a full text searchable SQLite database.

Messaging

WhatsApp MCP

An MCP bridge into WhatsApp pulls chats and media so client conversations can be searched, summarized, and folded into the same operational memory as Slack and email.

Research

Helium 10 MCP Integration

A working MCP bridge into the Helium 10 suite runs through a remote proxy with a scope override we set up when the native route refused to authenticate, so keyword research, listing analysis, and profit data answer inside the same AI workflows as everything else.

Pipelines

Data and operations pipelines

Scheduled runs turn raw activity into decisions, because the daily work of 15 to 20 accounts only stays consistent when the plumbing is code.

Operations Hub

Tasks Hub

A task engine watches Slack mentions across three workspaces, uses AI to decide accountability and extract the task, files it to Google Tasks, notifies us on Discord, and maintains a repository database of over 42,000 cross-channel work log rows that gives every new task its full account history.

Forecasting

Forecast Tracking that Syncs

This is the sync layer behind our 90 day per-account forecasts, keeping projections, actuals, and pacing in one sheet per account so every weekly report is measured against a written plan rather than a feeling.

Meetings

Krisp Meeting Pipeline

A pipeline ingests meeting transcripts, extracts the action items with AI, and turns them into tracked tasks, because decisions made on calls used to evaporate and now they land in a queue with an owner.

Meetings

Discord Meeting Recorder

A Discord voice channel recorder captures per-user audio to separate WAV tracks for clean transcription, built for the team calls that no meeting bot could join.

Rank Tracking

DataDive API Pipeline

A client for the DataDive API drives Rank Radar keyword tracking, pulls niche and ranking juice data, and writes the tracking sheets our ranking strategy runs on, because rank movements only matter when they land next to the spend that caused them.

Marketplace Analytics

MerchantSpring API Client

A reporting client for the MerchantSpring API runs the full create, poll, and download flow, which feeds our ads team tracking sheets and the daily sales pulls behind several of the case studies on this site.

Apps & Extensions

Extensions and apps

Smaller builds that remove daily friction sit here.

Chrome Extension

Chrome Memory Saver Setup

A tab management extension suspends idle tabs while keeping chosen service tabs alive, built because a working browser with two hundred tabs is a real operating condition and not a joke.

App

Speech Coach

A speaking practice app records, transcribes, and scores delivery, which we built to sharpen the client facing half of the job because clear speech closes accounts as surely as clear reporting.

Client Systems

Private client automations

We also run client specific systems that stay private by design, including hourly Prime event budget pipelines, DSP report writers, an inventory aware supply chain sync, and alerting bots, and each one is described in the case studies where its results show up.
